# 2026-10-06

## GitHub 开源发布（GPLv3）

- 仓库：`https://github.com/OatmeaILL/MaiBill`（public，分支 main，112 文件）
- Release v2.4：APK 资产名必须用 **ASCII**（`mai-bill-v2.4.apk`）——中文文件名经 bash 传参给 `gh` 会被吞成 `-v2.4.apk`，需要字节法或改 ASCII 名
- LICENSE 取自 spdx/license-list-data（`gh api repos/spdx/license-list-data/contents/text/GPL-3.0-only.txt | base64 -d`），因为 gnu.org 走代理 502
- 删坏资产要用 `gh api -X DELETE repos/.../releases/assets/<id>`，`gh release delete-asset -y` 解析中文名会失败

## 安全整改：签名配置外移

`app/build.gradle.kts` 原本硬编码 `storePassword = "maibill123"` 等四项，直接推送等于永久公开密钥。已改为：
- 读取根目录 `keystore.properties`（已 gitignore）
- 该文件不存在时回退 debug 签名，保证新克隆仓库可直接构建
- 本地已创建 `keystore.properties` 指向 `build-env/maibill.jks`，原构建流程不受影响
- 改后已验证：`gradle :app:assembleRelease` BUILD SUCCESSFUL、`testReleaseUnitTest` 通过
